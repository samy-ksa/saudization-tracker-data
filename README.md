# Saudi Arabia Saudization & Nitaqat decisions, 2026

A dated, sourced dataset of **17 official Saudization (localisation) and Nitaqat decisions** announced or taking effect between November 2025 and April 2028, maintained by [SHIFT Observatory](https://www.ksashiftobservatory.online/en/saudization-tracker).

Each record has: announcement date, effective date, deciding authority, who is affected, a one-sentence summary, a primary source (SPA, HRSD, HRDF or equivalent) and a second source, plus a confidence level. Records without a primary source or two independent media are not included. Where sources disagree on a date, the disagreement is stated in `notes`.

## Files
- `data/saudization-decisions.json`: full data
- `data/saudization-decisions.csv`: same data, one row per decision

## Live version and timeline
https://www.ksashiftobservatory.online/en/saudization-tracker (also in [French](https://www.ksashiftobservatory.online/fr/saudization-tracker) and [Arabic](https://www.ksashiftobservatory.online/ar/saudization-tracker)). The live page is updated when new decisions are announced; this repository is a snapshot published on 15 November 2026.
